# Реализация Forma

## Подготовлено в коде

- Воспроизводимый typecheck, актуальная стабильная версия Next.js, CI с PostgreSQL.
- OpenRouter, обработка ошибок, JSON Schema и смысловые проверки ответа.
- Supabase Auth, профиль, изоляция данных, production без demo-user.
- Закрытые для внешних ролей таблицы PostgreSQL, отдельный URL миграций и инструкция запуска с нуля.
- Миграции существующей базы и снимки параметров тренировок.
- Программы: стартовый план, генерация, редактор, активный выбор, архив.
- Тренировки: начало, восстановление, журнал, исправления, таймер, завершение, отмена.
- Реальная статистика, мобильная навигация и обратная связь.
- История и оценки включаются в следующую AI-генерацию.

## Для первого живого релиза

- Настроить PostgreSQL, Supabase Auth/SMTP и OpenRouter в окружении.
- Проверить реальные письма регистрации и восстановления.
- Проверить выбранную AI-модель на анкетах с 1, 3 и 7 днями.
- Развернуть приложение и пройти сценарий с двумя независимыми аккаунтами.
- Настроить резервное копирование, мониторинг /api/health и бюджет AI.

## После первого релиза

По обратной связи пользователей: календарь расписания, чат с тренером, уведомления и расширенная аналитика. Эти функции не нужны для прохождения базового сценария «программа → тренировка → результат → рекомендация».
